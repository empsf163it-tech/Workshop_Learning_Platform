Assistive learning tools

Helpful tools, without unnecessary complexity.

AbilityLearn brings supportive digital features into the learning journey so learners can interact with content in ways that work for them.

Technology with purpose

Support the way a learner already learns

Assistive features should make content easier to access and use, not add another layer to navigate.

  • ✓Reading support
    Helpful presentation options can make longer content easier to follow.
  • ✓Focus-friendly layouts
    Reduce visual clutter and keep attention on the current learning task.
  • ✓Alternative interactions
    Provide practical ways to interact with digital activities and resources.
Toolset

Examples of supportive features

R

Reading preferences

Adjustable presentation patterns can support comfortable reading and focused study.

F

Focus support

Simple, uncluttered learning views can help learners stay with one task at a time.

P

Progress cues

Clear visual cues show where a learner is in a lesson or learning path.
