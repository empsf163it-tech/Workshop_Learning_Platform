# AbilityLearn — Special Needs Learning Platform

This package was transformed from the supplied flower-shop website into a 5-page AbilityLearn concept.

Pages:
- index.html
- learning.html
- tools.html
- support.html
- about.html

Removed from the original package:
- Git repository metadata
- Flower-shop pages and checkout/authentication pages
- Flower product/image assets
- Unused scripts/assets

The website uses one font family (Nunito Sans), a single plum-based theme with neutrals, LTR layout, and no login/signup/dashboard.
